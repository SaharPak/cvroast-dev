The rubric

Six dimensions, weighted by what AI hiring managers actually care about.

Backed by research from Karpathy, Lenny Rachitsky, Marty Cagan, Claire Vo, and FAANG recruiters.

Shipped Evidence

30%
Quantified Impact
Numbers in every bullet — scope, speed, adoption, savings
20%
AI Tooling Visibility

ATS Compatibility

15%

Install

Two minutes. No signup. No API key.

Pick your environment. The skill auto-loads when you ask for a CV review.

→ Cursor 

# Personal install (works in every project)
mkdir -p ~/.cursor/skills && cd ~/.cursor/skills
git clone https://github.com/SaharPak/ai-cv-roast.git

→ Claude Code 

# Personal install (works in every project)
mkdir -p ~/.claude/skills && cd ~/.claude/skills
git clone https://github.com/SaharPak/ai-cv-roast.git

→ Then ask your AI agent 

"Roast my CV using the ai-cv-roast skill."

Paste your CV (markdown, plain text, or attach the PDF). Get back: a 0-5 score, the top issues ranked by impact, and concrete before/after rewrites.
